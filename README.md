# JavaScript DOM Lab

Six cumulative browser-based challenges with live demos, step-by-step hints, an in-browser JavaScript checker, quick checks, and solutions. The final challenge includes the complete student project. Completion is saved in the current browser when local storage is available.

## Preview

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript and needs no build or dependencies.

## Publish to GitHub Pages

1. Upload the contents of this folder to the root of a GitHub repository. Keep `index.html`, `styles.css`, `lessons.js`, `lab.js`, and `practice.js` together.
2. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose your default branch (usually `main`) and **/ (root)**, then save.
3. Once Pages finishes publishing, use **Visit site** to open the site and copy its URL for students.

The site also works from a subfolder of an already published GitHub Pages site. Upload the whole folder into the published source and link to `./dom-practice/` from the site homepage.

[GitHub Pages publishing documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
